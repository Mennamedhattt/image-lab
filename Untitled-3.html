Since each channel has 8 bits, the number of possible levels is 2⁸. What is that number? And if a channel only had 4 bits, how many levels would that give?

2⁸ = 256 levels (0 to 255). With 4 bits: 2⁴ = 16 levels only (0 to 15) — a much coarser grayscale gradient.
